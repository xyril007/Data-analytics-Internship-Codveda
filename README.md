## 1. Exploratory Data Analysis — Iris Dataset

### Objective

Perform exploratory analysis on the Iris dataset to understand the distribution and relationships between flower measurements and species.

### Key Activities

* Loaded and inspected the dataset
* Checked data structure and data types
* Examined descriptive statistics
* Investigated data quality
* Analyzed distributions
* Compared measurements across species
* Created visualizations to identify patterns and relationships

### Skills Demonstrated

**Python • Pandas • NumPy • Matplotlib • Seaborn • Exploratory Data Analysis • Data Visualization**

#  Advanced Projects

## 5. Customer Churn Prediction

### Objective

Develop a predictive analytics workflow to identify patterns associated with customer churn and evaluate the ability of a machine learning model to predict customer attrition.

### Dataset

The project uses customer churn datasets containing separate training/testing data files:

* `churn-bigml-80.csv`
* `churn-bigml-20.csv`

### Key Activities

* Loaded and explored customer data
* Investigated dataset characteristics
* Prepared variables for modeling
* Analyzed customer churn patterns
* Built a predictive modeling workflow
* Evaluated model predictions
* Compared model performance using appropriate evaluation metrics
* Interpreted factors associated with churn

### Business Value

Customer churn prediction can help organizations:

* Identify customers at higher risk of leaving
* Prioritize retention activities
* Improve customer experience
* Allocate retention resources more efficiently
* Support data-driven customer relationship strategies

### Skills Demonstrated

**Python • Pandas • NumPy • Scikit-learn • Machine Learning • Classification • Predictive Analytics • Model Evaluation**
